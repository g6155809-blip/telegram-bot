# Telegram AI Bot

Готовый Telegram-бот на TypeScript с AI-ответами, генерацией изображений, дневным лимитом, алмазами, реферальной системой, промокодами и админ-панелью.

## Что умеет бот

- отвечает на вопросы через OpenAI-совместимый AI API;
- создаёт изображения по описанию;
- выдаёт 5 бесплатных запросов в день и переносит дополнительные запросы, купленные за алмазы;
- показывает профиль: регистрацию, лимиты, алмазы и рефералов;
- даёт реферальную ссылку и начисляет 10 алмазов за нового пользователя;
- принимает промокоды;
- позволяет владельцу и выданным администраторам создавать промокоды, выдавать запросы и назначать администраторов.

Функции SMS-бомберов, массовой отправки сообщений и получения банковских кодов намеренно отсутствуют.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather).
2. Скопируйте `.env.example` в `.env`.
3. Заполните `TELEGRAM_BOT_TOKEN` и `ADMIN_TELEGRAM_ID`.
4. Подключите OpenAI через Replit AI Integration или укажите `OPENAI_API_KEY`.
5. Установите зависимости и запустите:

```bash
pnpm install
pnpm --filter @workspace/telegram-bot run start
```

Для разработки:

```bash
pnpm --filter @workspace/telegram-bot run dev
```

Данные пользователей и промокодов хранятся в файле `data/bot-state.json`. Перед запуском в нескольких экземплярах замените хранилище на общую БД.
